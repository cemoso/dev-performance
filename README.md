# Developer Performance Review Framework

## Executive Summary

A comprehensive, objective framework for evaluating software developer performance across five core competencies. Designed for quarterly reviews with annual summaries.

### Key Features

- **Standardized scoring** (1-5 scale) ensuring consistent, fair evaluations
- **Weighted categories** reflecting organizational priorities
- **Evidence-based assessment** with documented criteria
- **Goal tracking** for continuous professional development

### Evaluation Categories

| Category | Weight | Focus |
|----------|--------|-------|
| Technical Growth & Problem Solving | 20% | Learning, innovation, technical debt reduction |
| Knowledge Distribution & Bus Factor | 25% | Documentation, onboarding, standards compliance |
| Output & Code Quality | 25% | Commits, PR quality, code reviews, bug rates |
| Kaizen - Continuous Improvement | 15% | Process improvements, mentoring, team friction |
| Collaboration & Communication | 15% | Responsiveness, unblocking, clear updates |

### Performance Ratings

| Total Score | Rating |
|-------------|--------|
| 90 to 100 | Exceptional |
| 80 to below 90 | Exceeds Expectations |
| 60 to below 80 | Meets Expectations |
| 40 to below 60 | Needs Improvement |
| Below 40 | Does Not Meet Expectations |

Each criterion is scored 1-5. Category totals are normalized by weight: `(score ÷ max) × weight`, summing to 100.
